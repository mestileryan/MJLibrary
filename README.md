# MJLibrary

Bibliothèque de pistes audio pour meneur de jeu de rôle, pensée pour alimenter
[MJScreen](https://github.com/mestileryan/MJScreen).

Application web entièrement statique (Vite, React, TypeScript, Tailwind), publiée sur
GitHub Pages sous `/MJLibrary/`.

## Installation

```sh
npm install
npm run dev
```

L'application est servie sur http://localhost:3300/MJLibrary/.
